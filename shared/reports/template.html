02 / Local storage

文件与 SQLite

Node fs / Rust std::fs / Dart io；各使用原生 SQLite。每项预热一次、测量五次。单文件写入包含 flush/fsync，小文件创建不逐文件同步。读取是页缓存未控制的暖读，不能等同磁盘冷读。

存储计时在原生 API 内执行，初始化、内容/行数校验和清理不计时。随机数据是重复的固定种子 1MiB 高熵块；随机 IO 为 2048 次 4KiB 操作。SQLite 版本会单独显示，不把不同引擎版本当作完全相同实现。
03 / Mesh & skeletal animation

从参数扩展到 2.1GB

骨骼、三角形、角色数量、贴图分辨率分别扩展。静态载入指标在每次准备阶段采集。TTFM 是 CPU 提交加下一次回调的代理，非 GPU 完成确认；GPU 上传/解码尚未独立计时。

Tauri 的进程树采集不完整覆盖系统 WebKit XPC 进程，CPU/RSS 不用于跨壳比较。系统缓存未控制，固定测试顺序不支持把载入时间差异全部归因于运行时。
04 / Pixel consistency

先看布局，再看像素

六个固定 fixture，真实原生壳截图。统一 1280×800、DPR2、英文、浅色、固定状态、相同本地 IBM Plex TTF。Flutter 作为自绘语义视觉参考。

Pixel diff 阈值 0.1，忽略 AA 分类；SSIM 在固定 640×400 采样图计算。Geometry diff 比较实际渲染节点边界。文字边界由 Web Range 与 Flutter TextPainter 得到，其测量定义不同，不按 bit-identical 判定合格。
